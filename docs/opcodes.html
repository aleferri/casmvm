CASMVM opcodes

Execution model

CASMVM is a register machine. A program is a list of callables; each callable is a flat sequence of opcodes. Every value lives in a numbered local, written %N and holding a 64 bit integer. Opcodes that produce a value write their result into the local on the left of the = sign. Call arguments arrive in %0 .. %N-1; return values live in a separate register file, filled by leave and read back by the caller through enter.

Comments start with ; and run to the end of the line. Commas between operands are optional separators. Execution of a .csm file starts from the first callable (index 0).

Shapes

Value opcodes carry a shape that truncates the result to the given width; signed shapes sign-extend the truncated value back to 64 bits.

Signedi8i16i32i64
Unsignedu8u16u32u64

Jump offsets

The offsets of branch and goto are relative to the next instruction: an offset of 0 falls through, -1 repeats the jump instruction itself.

Callable header (.csm files)

fn <name> <arity> [<returns>]

Starts a new callable. arity is the number of parameters; the trailing returns count is accepted but currently informative only.

Opcodes

  1. const

    %d = const <shape> <value>
    Load the integer constant into local %d, reshaped to the given shape.

  2. local

    %d = local <shape> %s
    Copy local %s into local %d, reshaped to the given shape.

  3. binary operations

    %d = <op> <shape> %a %b
    Apply the binary operator to %a and %b, reshape the result and store it in %d. Available operators:
    Arithmeticadd sub mul div mod
    Bitwiseand or xor shl shr
    Comparison (yield 0 or 1)cmpeq cmpne cmplt cmple cmpgt cmpge
    Logical (yield 0 or 1)andl orl
    div and mod stop execution with an error when the divisor is zero.

  4. unary operations

    %d = <op> <shape> %a
    Apply the unary operator to %a, reshape the result and store it in %d. Available operators: neg (arithmetic negation), not (bitwise complement), notl (logical not, yields 0 or 1).

  5. enter

    [ %r0 %r1 ... ] = enter <callable> %a %b ...
    Call the callable with the given index, passing the listed locals as arguments. The callee's return values are copied into %r0 %r1 ...; their count must match the number of values the callee leaves, otherwise execution stops with an error.

  6. leave

    leave %a %b ...
    Copy the listed locals into the return registers and leave the current callable. The list may be empty.

  7. branch

    branch %ref <value> <offset>
    If local %ref equals the constant value, jump by offset (relative to the next instruction).

  8. goto

    goto <offset>
    Unconditional jump by offset (relative to the next instruction).

  9. sigwarn

    sigwarn %ref "message"
    Log a warning composed of the message followed by the value of %ref. Execution continues.

  10. sigerr

    sigerr %ref "message"
    Log an error composed of the message followed by the value of %ref, then stop execution with that error.

Example

fn main 0 1
%0 = const i16 42
[ %1 ] = enter 1 %0     ; call triple(42)
leave %1

fn triple 1 1
%1 = const i16 3
%2 = mul i16 %0 %1
leave %2
